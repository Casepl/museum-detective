# Museum Detective assets

Оригинальный набор для учебной игры про Байеса. Сгенерирован встроенным
ImageGen 30 октября 2026 года. Исходные поисковые превью из беседы ChatGPT не
копировались.

## Files

- `museum-night.png` — фон ночного музея, 1672×941, RGB.
- `suspects.png` — Алексей, Мария и Виктор слева направо, 2172×724, RGBA.
- `clues.png` — сетка 3×2: камера, отпечаток, ключ-карта, датчик движения,
  след обуви, сломанная защёлка; 1536×1024, RGBA.

## Intended use

На первом эфире файлы служат визуальным вступлением и готовым фундаментом для
будущей графической оболочки. Основная игра сначала реализуется в терминале на
чистом Python и не зависит от изображений.

## Prompt summaries

1. Ночной музей: 16-bit pixel art, пустая подсвеченная витрина, камера,
   служебная дверь и следы, navy/teal/amber, без текста и персонажей.
2. Подозреваемые: три отдельных bust portrait в одном горизонтальном листе —
   охранник Алексей, реставратор Мария, коллекционер Виктор; прозрачный фон.
3. Улики: сетка 3×2 из камеры, отпечатка, ключ-карты, датчика, следа обуви и
   сломанной защёлки; прозрачный фон, без подписей.
